# Landing page

`index.html` is the single static page for `prdgenie.stillform.app`, hosted on ChatGPT Sites. Its own source has no scripts, web fonts, analytics, cookies or forms. ChatGPT Sites may add platform security scripts and cookies; the published footer distinguishes these from tracking by the page itself. GitHub remains the source home.

The page implements the Claude Design website specification. Before publishing:

- `hero.webp` and `hero@2x.webp` are a capture of the signed v0.1.0-rc.4 app (2240 x 1400, light mode) showing a real model proposal on synthetic research notes. Replace them when the main window changes.
- Confirm the v0.1.0-rc.4 release page linked from the download buttons exists.
- Retain the platform-qualified footer: "This page has no analytics, forms or tracking of its own." Check hosting additions before making any broader privacy claim.
- `prd-genie-logo.svg` is the approved Claude Design icon, identical to `scripts/mac/AppIcon.svg`.
- Check the page contains no em dashes.

When a later release ships, update the version in the hero buttons and status line, the Get it body, buttons, file note and spec list, and the meta description if its wording changes.
