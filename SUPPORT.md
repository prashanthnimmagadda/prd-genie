# Support

Use GitHub Discussions for usage questions. Use issue forms for reproducible defects and focused feature proposals.

Before reporting a problem:

1. Check the README troubleshooting section.
2. Confirm Node.js 22 or 24.
3. Run `npm run typecheck` and the relevant test.
4. Remove credentials and confidential project data from logs.

Security issues belong in the private process described in `SECURITY.md`.
