# Support

Use [GitHub Discussions](https://github.com/prashanthnimmagadda/prd-genie/discussions) for usage questions. Use [issue forms](https://github.com/prashanthnimmagadda/prd-genie/issues/new/choose) for reproducible defects and focused feature proposals.

Before reporting a problem:

1. Check the README troubleshooting section.
2. Confirm Node.js 22 or 24.
3. Include your operating system, `node --version`, `npm --version`, `git rev-parse --short HEAD`, the command or action that failed, and the redacted error. Contributors can additionally run `npm run typecheck` and the relevant test.
4. Remove credentials and confidential project data from logs.

Security issues belong in the private process described in `SECURITY.md`.
